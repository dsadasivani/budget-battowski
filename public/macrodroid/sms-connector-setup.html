Budget Battowski SMS connector

This connector forwards candidate bank SMS messages for review. It never creates an expense automatically.

Connect

  1. Install MacroDroid and grant its SMS permission.
  2. In Budget Battowski, open Settings → Automatic SMS Transactions and choose Connect Android.
  3. Enable the Budget Battowski connector macro. Enter the displayed six-digit code when prompted.
  4. Return to Settings and verify that the device appears as Active.

Connector behavior

  • The macro queues each candidate before sending it.
  • Network and server failures remain queued and retry every 15 minutes.
  • Authentication failures stop retrying and require reconnection.
  • A heartbeat runs every three hours. A stale warning means capture may be incomplete.
  • OTP, verification, and obvious promotional messages are excluded. The server validates every message again.

Privacy

Do not share an already-paired macro export. A distributable connector must have empty device, queue, response, and test-message variables. Budget Battowski never asks you to paste a device token, Firebase UID, or workspace ID.

Troubleshooting

  • If standard SMS detection fails, open the SMS Received trigger and try Monitor Inbox.
  • MacroDroid does not detect RCS/chat messages through the SMS trigger.
  • If MacroDroid was force-stopped, messages it never received cannot be recovered automatically.
  • If a device was disconnected, generate a new pairing code; revoked credentials cannot be restored.

For the complete macro blueprint and API behavior, see docs/sms-transaction-automation.md in the Budget Battowski repository.
